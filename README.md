## Установка
Контейнеры собираются на GitHub-репозитории с помощью docker-compose.yml
Для запуска контейнеров на сервере необходимо наличие .env файла и docker-compose.pub.yml

Так же возможен локальный запуск через установку зависимостей, для этого необходимо создать файлы 
backend/.env
frontend/.env
